# 📊 PANELPRO — Admin Dashboard Template

A premium, framework-free HTML template for admin dashboards and analytics panels. The design pairs a deep-navy sidebar canvas with indigo and emerald accent charts, an Inter typographic system, and clean KPI cards — built for SaaS products, control panels, and internal tools that want to feel sharp, fast, and production-ready.

## 🎨 Design System

| Token | Value | Usage |
|-------|-------|-------|
| `--navy` | `#1A1D3E` | Deep navy — sidebar canvas, dark accents |
| `--indigo` | `#4F46E5` | Indigo — primary actions, active nav, primary charts |
| `--emerald` | `#10B981` | Emerald — growth bars, success states, highlights |
| `--slate` | `#64748B` | Slate — secondary text, muted charts, borders |
| `--bg` | `#F1F5F9` | Light grey — page background |
| `--white` | `#FFFFFF` | White — cards, panels, topbar |
| `--red` | `#EF4444` | Red — declines, alerts, destructive actions |
| `--amber` | `#F59E0B` | Amber — warnings, pending badges, accents |
| Headings | Inter 600/700/800 | Semibold–extra bold — titles, KPI values |
| Body | Inter 400/500 | Clean modern sans — content, tables |

## 📄 Pages

| Page | Description | Sections |
|------|-------------|----------|
| [index.html](index.html) | Dashboard — live overview at a glance | KPI stats bar (Revenue, Users, Sessions, Conversion), Revenue bar chart, Traffic sources donut, Recent Activity feed, Recent Orders table |
| [analytics.html](analytics.html) | Deep traffic & conversion reporting | KPI stats bar (Page Views, Bounce, Session, New Users), Sessions & Page Views chart, Top Pages table, Conversion Funnel table |
| [users.html](users.html) | Manage the user base | Filter bar (search, role, status), Users table with avatars, role & status badges, edit / delete actions |
| [settings.html](settings.html) | Account & security preferences | Profile form, Account (role / timezone / language), Notifications toggles, Security password form |
| [404.html](404.html) | Delisted page | Giant 404 code, error copy, back-to-dashboard + manage-users links |

## ⚙️ Tech Stack

- **HTML5** — semantic markup, accessibility-first
- **CSS3** — custom properties, Grid, Flexbox, conic-gradient donut, pure-CSS bar charts
- **Vanilla JS** — IntersectionObserver, KPI count-up, sidebar collapse, mobile nav, form validation
- **Fonts** — Google Fonts (Inter)
